## 🇲🇾 IEM – Institution of Engineers Malaysia Club | People Registration System

This project is a simple front-end web application developed for the 
**Institution of Engineers Malaysia (IEM) Club** to collect and store 
basic member information such as Name, ID, and Age.  
It works entirely on the browser using **localStorage**, with no backend needed.

### 🔧 Features
- Add new members through a clean, simple form  
- Auto-save member data using the browser’s **localStorage**  
- Automatically loads all saved members on page load  
- Fully client-side (HTML + Vanilla JavaScript)  
- No server, no database required  

### 🛠️ Tech Stack
- **HTML5**  
- **JavaScript (Vanilla)**  
- **LocalStorage API**

### 📂 Included Files
- `index.html` — UI and form  
- `script.js` — logic for adding, listing, and saving members  

### 🚀 How It Works
1. Open the `index.html` file in any browser  
2. Enter the member's Name, ID, and Age  
3. Click **Add Person**  
4. The member instantly appears in the list  
5. Data is saved automatically and stays even after closing the page  

### 🎯 Purpose
This tool was created to help the **IEM Club** quickly register and track 
its members in a simple, offline-friendly way during events, activities, 
and club meetings.
